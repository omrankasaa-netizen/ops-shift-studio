Upload to GitHub

  1. Download all 6 files above
  2. Go to github.com/omrankasaa-netizen/ops-shift-studio
  3. Click Add file → Upload files
  4. Drag all 6 downloaded files into the upload area
  5. Commit message: Initial OPS/SHIFT website
  6. Click Commit changes
  7. Go to Settings → Pages
  8. Under Source, select Deploy from a branch
  9. Select main branch and /(root) folder
  10. Click Save
Your site will be live at https://omrankasaa-netizen.github.io/ops-shift-studio/ within a few minutes.
